#### 7.1 采纳的论证

- 单语种语料（各自语种内）、领域窄（6～9 年级固定知识点）、chunk 短（200～400 字）——三条均属 MRL 前缀维度的适用条件。
- 真实瓶颈在**近义知识点混淆、跨版本/跨学科串味、公式图表**，不在维度。
- 1024 下 cosine 分布被压缩：兄弟知识点（相反数/倒数、一次函数/正比例函数）原本 cosine 已在 0.85 以上，压缩后挤在 0.88～0.93；top-1 被抢是**排序区分度不足**，不是模型认错。
- 「能，但必须配 rerank 或 hybrid，不能靠单路 dense 硬顶」——项目 hybrid（dense + `text_jieba` 词法 RRF k=60）**已具备**，满足该前提的一半。

#### 7.4 三档对比验证的落地（替换「半天搞定」）

1. 1024 / 2048 / 4096 三档通过**同一 Qwen3-8B 模型的 MRL 截断**实现（支持 32～4096），**不重复跑三次 embedding**；每档截断后各自重新 L2 归一化（DEC-P2 S1）。
2. 指标：`recall@20`（召回是否够给 hybrid/rerank 留纠错空间）+ `top-1 准确率`；在**当前基线（0.38）与按 DEC-P9 复标得到的新阈值下分别评估**——旧值作对照，新值按 D08 §4.6 流程产出，不是为了挽救效果而临时下调。
3. 判据：1024 下 `recall@20` 比 4096 掉 ≤3 点 → 通过；`top-1` 掉 >8 点 → 近义混淆严重，**启用 DEC-P8 已就位的 rerank**（不再临时排期），仍不达标才上 2048 对照档，**禁止用无依据的下调挽救**；**近义对子集单独统计**（这一小撮才反映真实风险）。
4. 执行：按 D08 标注纪律，标注者 ≠ 实现方，纳入 P0-5 / P3-5 排期。

### DEC-P8 首期引入 rerank（重排器）

| 字段 | 内容 |
|---|---|
| 输入 | 2026-11-24 用户确认「引入 rerank」；DEC-P7 M4 原为「重评不达标时条件触发」，本次**升级为首期必做** |
| 决策 | **首期必做**：`BM25(text_jieba + 学科术语词典) ⊕ dense(cosine) → RRF(k=60) → top-20 → rerank → top-3~5`。默认模型 `Qwen3-Reranker-0.6B`（与 Qwen3-Embedding-8B 同族），备选 `bge-reranker-v2-m3`；**项目当前无 rerank 实现，属新增能力** |
| 理由 | 1024 维压缩 cosine 分布后，近义兄弟知识点抢 top-1 属**排序区分度**问题；按 D27 §14.4「重排器优先于加维度」。hybrid 解决召回、rerank 解决排序，二者缺一不可 |
| 排期影响 | 原 15 周 → **17 周**（+2 周：端口/模型服务/超时降级 1 周，A/B 评测与近义对反证 1 周）；标注/评审资源不变 |

#### 8.1 接入位置与红线（不可协商）

1. **不新增第二套检索架构**：RRF `k=60` 不变，`JdbcRetrievalRepository` 仍是唯一生产检索真源；rerank 只消费其 top-20 候选。
2. **门禁仍在融合阶段以相关性分判定**（排序键=融合分 / 门禁键=相关性分分离；当前基线 0.38，按 DEC-P9 复标后取新值）。rerank 分数**只用于排序与截取**，⛔ 不得覆盖、绕过或替代门禁判定；被门禁拒绝的候选即使 rerank 高分也不得进入结果。
3. **不为救效果而下调阈值**：rerank 不达标须按 D27 §14.5 决策树处理（重排/微调/2048 档），⛔ 禁止无依据下调 `RAG_RETRIEVAL_MIN_SCORE`；如确因结构变更需要调整，只能走 DEC-P9 的复标流程。
4. **fail-closed + 时延预算**：rerank 服务不可用/超时不得静默返回未重排结果冒充成功；须显式标记 `degraded` 并告警（SSE/响应侧可见），P95 时延在灰度中实测，避免叠加既有并发=1 的队头阻塞。

#### 8.2 验收与反证

| 验证项 | 判据 |
|---|---|
| A/B 对照 | 同一黄金集跑 `1024+无 rerank` / `1024+rerank`（/ 4096 对照档），记录 `recall@20`、`top-1`、`nDCG@5`、P95 时延；禁止只看 top-1 |
| 近义对反证 | TRAP-NEARMISS 子集 top-1 单独统计：引入 rerank 后须转绿，**撤掉 rerank 须转红**（确定性反证） |
| 召回不可救 | `recall@20` 掉 >3 点 → ABORT 换维（DEC-P2）；**rerank 救不了召回**，不得用 top-1 增益掩盖召回退化 |
| 门禁不覆盖 | 构造「rerank 高分但融合相关性分 <当前生效阈值」候选，必须被拒（RC-09 门禁一致性；生效值由检索响应带回，不硬编码，见 D20） |
| 服务故障 | rerank 超时/不可用 → 显式 `degraded` + 告警，不静默通过 |

> **诚实边界**：rerank 服务在项目中当前不存在（D02/D05/D12/D27 仅文档提及）。DEC-P8 是新增能力而非复用；模型须真实部署、端点与超时验证通过后才可宣称生效。

### DEC-P9 相关性门禁阈值是标定基线，结构变更后必须复标

| 字段 | 内容 |
|---|---|
| 输入 | 2026-11-24 用户口径纠正：`0.38` 是前期测试得出的结论，**不要写死**；后续改动需重新测定 |
| 决策 | **0.38 是「当前标定基线」，不是物理常量、不是不可变红线的数值**。它来自 D08 §4.6.1（2026-10-28 首次实测标定，16 正/8 近邻/10 远域、样本不足属**指示性**标定）。任何改变相关性分分布的结构性变更后，**必须按 D08 §4.6 重新标定并替换基线** |
| 纠偏 | 本文 v1.0~v1.2 与 D28 v1.0~v1.3 中「不调阈值」「禁止调 0.38」「0.38 门禁不下调」的表述**过度收紧**，一律以本决策为准：禁止的是**无依据下调以掩盖效果退化**，不是禁止经流程的复标 |
| 触发复标的变更 | ① Embedding 换维 4096→1024（DEC-P2）；② 引入 rerank（DEC-P8）；③ 输入模板 / chunk 长度 / 切分策略变更；④ 换 Embedding 模型或 pooling/instruction；⑤ 语料扩量达到 D08 T-5 每层 ≥100 样本；⑥ 相关性分计算逻辑变更 |
| 复标流程（D08 §4.6 T-1~T-6） | ① 按 T-2 用评测集在真实语料上实测分布（P50 分位作初始门禁线，或按 D08 §4.6.1 的「远域负例分布上界」口径，**须评审确认口径**）；② 按 T-5 每层 ≥100 有效样本，不足则该层标「样本不足，暂不设门禁」只观察；③ 按 T-3 阈值只能变严，放宽须走变更流程 + 外部抽检；④ 按 T-4 更新 D08 表格 + 升评测集版本 + §9 留痕 + 附前后实测对比；⑤ 新值写入 D08 §7.2 基线快照后才生效 |
| 代码与配置落点 | `RAG_RETRIEVAL_MIN_SCORE` 是唯一生效源；**前端不得硬编码 `RAG_SCORE_THRESHOLD = 0.38`**（D20 已登记该漂移缺陷），生效值随检索响应返回；文档中统一写「当前基线（复标前 0.38）」，禁止把 0.38 写成常量语义 |
