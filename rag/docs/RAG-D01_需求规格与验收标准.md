## 1. 需求分级

| 级别 | 含义 | 缺失后果 |
|---|---|---|
| **MUST** | 不满足即阻断上线 | 教学事故（串版本/泄题/编造出处） |
| **SHOULD** | 影响质量但不阻断 | 体验下降、召回不全 |
| **COULD** | 可延后 | 锦上添花 |

## 2. 功能需求

### 2.1 语料治理（FR-RAG-001 ～ 005）

| ID | 级别 | 需求 | 验收条件 | 测试 ID |
|---|---|---|---|---|
| FR-RAG-001 | MUST | 语料来源须登记后方可入库，含出版标识、权威等级、版权状态 | 未登记来源无法创建入库任务；`rag_source` 无 `trust_tier` 默认值可为 `VERIFIED` | AT-RAG-001 |
| FR-RAG-002 | MUST | 未通过校验的来源**不得**进入可检索索引 | `ver_status <> 'VERIFIED'` 的来源其片段检索结果恒为空 | AT-RAG-002 |
| FR-RAG-003 | MUST | 校验须留存可复核证据（方式、依据、时间、审核人） | `VERIFIED` 缺 `ver_evidence` 或 `verified_at` 时 DB 拒绝写入 | AT-RAG-003 |
| FR-RAG-004 | MUST | 校验结论过期后须重新校验 | 超过 `ver_valid_days` 的来源被判定为过期，行为符合 RAG-D07 §5 规定 | AT-RAG-004 |
| FR-RAG-005 | SHOULD | 撤回（takedown）后语料须从索引移除，历史引用链路不破坏 | `REVOKED` 来源的片段不再被召回；历史 `rag_answer_citation` 仍可解释 | AT-RAG-005 |

### 2.2 版本坐标系（FR-RAG-010 ～ 014）

| ID | 级别 | 需求 | 验收条件 | 测试 ID |
|---|---|---|---|---|
| FR-RAG-010 | MUST | 每个片段须绑定完整五轴版本坐标（学科/年级/册次/出版社/版次） | 缺任一轴的片段无法入库；`EditionCoordinate` 构造拒绝空版次 | AT-RAG-010 |
| FR-RAG-011 | MUST | 检索须按版本范围**硬过滤** | `STRICT` 模式下其他版本的片段召回数为 0 | AT-RAG-011 |
| FR-RAG-012 | MUST | 非首选版本命中时须显式标注差异 | `PREFERRED_WITH_FALLBACK` 命中异版本内容时结果携带版本不一致标记 | AT-RAG-012 |
| FR-RAG-013 | MUST | 回答中的引用须携带版本坐标快照 | `rag_answer_citation.edition_snapshot` 非空且与被引片段一致 | AT-RAG-013 |
| FR-RAG-014 | SHOULD | 旧版教材须保留可查（学生可能仍在用） | `effective_to` 之后的版本仍可被显式指定版本范围检索到 | AT-RAG-014 |

### 2.3 数据处理与切分（FR-RAG-020 ～ 026）

| ID | 级别 | 需求 | 验收条件 | 测试 ID |
|---|---|---|---|---|
| FR-RAG-020 | MUST | 切分边界须由**版面结构**决定，不得按固定 token 窗口 | 结构切分产出的片段与标题/题号/答案区边界对齐 | AT-RAG-020 |
| FR-RAG-021 | MUST | 须保留页码、章节路径、题号等物理定位信息 | 每个片段的 `locator` 四要素完整；`char_end >= char_start` | AT-RAG-021 |
| FR-RAG-022 | MUST | 答案区内容须被识别为独立角色，不得与正文混淆 | 答案区段落归类为 `EXERCISE_ANSWER`/`EXAMPLE_SOLUTION`；准确率纳入 L1 指标 | AT-RAG-022 |
| FR-RAG-023 | MUST | 题目与答案须通过 `exercise_ref` 配对 | 答案片段可反查到对应题号 | AT-RAG-023 |
| FR-RAG-024 | MUST | 知识点须显式挂接到片段（多对多） | 片段可按 `kp_ids` 反查知识点；挂接准确率纳入 L1 指标 | AT-RAG-024 |
| FR-RAG-025 | SHOULD | 切分须保留公式与表格的结构语义 | 公式块与表格块不被打散为无结构纯文本 | AT-RAG-025 |
| FR-RAG-026 | SHOULD | 噪声（页眉页脚/版权页/目录）须丢弃 | `BOILERPLATE` 角色片段不入索引 | AT-RAG-026 |

### 2.4 知识点本体（FR-RAG-030 ～ 033）

| ID | 级别 | 需求 | 验收条件 | 测试 ID |
|---|---|---|---|---|
| FR-RAG-030 | MUST | 知识点须有规范名 + 别名 | 别名命中与规范名命中等价（`KnowledgePoint.matches`） | AT-RAG-030 |
| FR-RAG-031 | MUST | 知识点须支持先修关系，且不得成环 | 自我先修被 DB 拒绝；环路由应用层校验拒绝 | AT-RAG-031 |
| FR-RAG-032 | MUST | 同一知识点的讲解与配套练习须成组召回 | 知识点定向检索时，讲解与练习片段同时出现在结果中 | AT-RAG-032 |
| FR-RAG-033 | SHOULD | 知识点匹配须为确定性匹配，不得单靠模型判定 | 挂接结果可复现（同语料同规则同结果） | AT-RAG-033 |

### 2.5 检索（FR-RAG-040 ～ 046）

| ID | 级别 | 需求 | 验收条件 | 测试 ID |
|---|---|---|---|---|
| FR-RAG-040 | MUST | 检索请求须携带模式 | `RetrievalRequest.mode` 必填 | AT-RAG-040 |
| FR-RAG-041 | MUST | `EXPLAIN`/`OVERVIEW` 模式**不得**召回答案类内容 | 过滤后结果中 `EXERCISE_ANSWER`/`EXAMPLE_SOLUTION` 数量为 0 | AT-RAG-041 |
| FR-RAG-042 | MUST | `SOLVE` 模式不得召回习题标准答案（但可召回例题解答） | 过滤后 `EXERCISE_ANSWER` 为 0，`EXAMPLE_SOLUTION` 可 > 0 | AT-RAG-042 |
| FR-RAG-043 | MUST | 角色过滤须在检索期完成，不得在生成期用 prompt 约束替代 | 断言进入 prompt 的内容中不含被禁角色 | AT-RAG-043 |
| FR-RAG-044 | MUST | 须有分数门禁，低于阈值判为「未找到依据」 | 门禁高于全部候选得分时结果为空 | AT-RAG-044 |
| FR-RAG-045 | MUST | 补全引入的片段须有区分于直接命中的分数基准 | 补全基准分 < 典型命中分 | AT-RAG-045 |
| FR-RAG-046 | SHOULD | 须支持多路召回（稠密 + 词法）融合 | 融合后的 Recall@k 不低于任一单路 | AT-RAG-046 |

### 2.6 引用与接地（FR-RAG-050 ～ 058）

| ID | 级别 | 需求 | 验收条件 | 测试 ID |
|---|---|---|---|---|
| FR-RAG-050 | MUST | 回答中每条实质断言须绑定至少一条引用 | 无引用断言 → 整体拒绝交付 | AT-RAG-050 |
| FR-RAG-051 | MUST | 引用须含**逐字引文**，且必须是被引片段的子串 | 引文非子串时构造失败 | AT-RAG-051 |
| FR-RAG-052 | MUST | 引用须指向真实存在的片段位置（存在性校验） | 指向不存在位置的引用 → 拒绝交付 | AT-RAG-052 |
| FR-RAG-053 | MUST | 须做蕴含判定：片段内容是否真的支撑该断言 | 蕴含度低于阈值 → 判为未/部分接地 | AT-RAG-053 |
| FR-RAG-054 | MUST | 须检测引用间的**事实冲突**并拒绝静默择一 | 冲突时拒绝交付并说明冲突 | AT-RAG-054 |
| FR-RAG-055 | MUST | 默认策略下不得在讲解回答中引用答案类内容 | `GroundingPolicy.allowsRole` 拒绝答案角色 | AT-RAG-055 |
| FR-RAG-056 | MUST | 接地不达标时须能「依据不足」作答，不得以参数内知识补写 | 检索为空时输出不含无出处断言 | AT-RAG-056 |
| FR-RAG-057 | MUST | 引用溯源链路须完整落库可审计 | `rag_answer_citation` 记录声明/引文/判定/版本快照 | AT-RAG-057 |
| FR-RAG-058 | SHOULD | 跨版本引用须被显式标注 | 引用集合版本不唯一时可检出 | AT-RAG-058 |

### 2.7 隔离与合规（FR-RAG-060 ～ 064）

| ID | 级别 | 需求 | 验收条件 | 测试 ID |
|---|---|---|---|---|
| FR-RAG-060 | MUST | 全部语料表启用 RLS + FORCE | 非特权角色下跨租户读为 0 | AT-RAG-060 |
| FR-RAG-061 | MUST | 跨租户写入须被拒绝 | 跨租户 INSERT 被 RLS 拒绝 | AT-RAG-061 |
| FR-RAG-062 | MUST | 应用连接须为非特权角色；启动时自检 | 特权角色启动被拒绝 | AT-RAG-062 |
| FR-RAG-063 | MUST | 教材全文不入数据库 | `rag_chunk.text` 仅存片段；整册正文在对象存储 | AT-RAG-063 |
| FR-RAG-064 | MUST | 语料访问须写审计且审计不可篡改 | 审计表 UPDATE/DELETE 被触发器拒绝 | AT-RAG-064 |

## 3. 非功能需求

| ID | 需求 | 目标 | 验证方式 | 状态 |
|---|---|---|---|---|
| NFR-RAG-001 | 检索延迟 | P95 ≤ 500ms（不含生成） | 压测 | 🟡 待实测 |
| NFR-RAG-002 | 端到端延迟 | P95 ≤ 8s（含生成） | 压测 | 🟡 待实测 |
| NFR-RAG-003 | 索引吞吐 | 单版本整册（300 页）入库 ≤ 30min | 压测 | 🟡 待实测 |
| NFR-RAG-004 | 规模 | 100 万片段下检索延迟劣化 ≤ 50% | 压测 | 🟡 待实测 |
| NFR-RAG-005 | 可用性 | 检索不可用时**降级为「依据不足」而非报错** | 故障注入 | 🟡 待实测 |
| NFR-RAG-006 | 可复现 | 同语料 + 同查询 + 同模型版本 → 同结果 | 回归 | 🟡 待实测 |
| NFR-RAG-007 | 成本 | 单次问答的模型调用数 ≤ 3（生成 + 蕴含 + 补判） | 埋点 | 🟡 待实测 |
| NFR-RAG-008 | 数据不出境 | 嵌入与蕴含判定模型须境内部署 | 架构评审 | 🟡 待落实 |

> 参照主平台 `P0-D04` §1「性能、容量、SLO、RPO/RTO 的数值需在 P1/P4 基于业务输入
> 和目标环境确认，P0 不虚构阈值」，本表中的目标值须在 RAG-D08 评测中实测后校准。

## 4. 缺陷与豁免规则（继承主平台 P0-D04 §4）

| 严重度 | 示例 | 处理规则 |
|---|---|---|
| **Sev-0** | 串版本导致错误内容、泄题、编造出处、跨租户语料泄露、无依据断言被交付 | 禁止上线；必须修复并复测 |
| **Sev-1** | 引用位置错误、版本标注缺失、冲突被静默择一 | 原则上阻断阶段门禁；例外需书面批准并限期 |
| **Sev-2** | 召回不全、排序不佳但无错答 | 登记责任人、期限，可按批准条件接受 |
| **Sev-3** | 展示与文案问题 | 纳入 Backlog |

## 5. AI 审查约束（继承 DEC-7 / ISO-1 ～ ISO-5）

| 规则 | 本项目适用内容 |
|---|---|
| ISO-1 | 评测集标注者与被评者上下文隔离；实现方不得为自己的实现签署评测结论 |
| ISO-2 | 审查方输入仅限：需求 ID、代码、测试结果、运行日志、DB 断言 |
| ISO-4 | 核心不变式（版本过滤、泄题闸门、接地裁决）由 AG-QA + AG-SEC 交叉审查，AG-ARC 不得自审 |
| ISO-5 | Sev-0/Sev-1 结论须项目负责人外部抽检，覆盖率 ≥ 30% 且含全部 Sev-0 项 |

> ⚠️ 与主平台 R-016 同源：同基座模型存在**相关盲区**，
> 「AI 看不出来的漏洞，AI 也分析不出来」。故 Sev-0 判定不得仅依赖 AI，
> 须有自动化测试证据 + 外部抽检。
