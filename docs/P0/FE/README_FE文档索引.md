### F1–F3 交付明细（2026-10-19）

**验证结果（实测）**

| 项 | 结果 |

| 生产构建 | 成功，203.70 kB（gzip 67.55 kB）|
| 产物密钥扫描 | **通过** |

**⚠️ 验证抓到的 P0 缺陷（已修复）**

`client.ts` 中 `login(payload)` 的形参名**遮蔽了同名的模块级 `request` 函数** →
运行时 `request2 is not a function` → **所有 HTTP 调用静默失败**。

> **为什么 5 个纯逻辑测试没发现**：它们都不经过 `client.ts`。
> **只有组件测试会真正发起请求**。分层测试有盲区——
> 不经过某模块的测试不会发现该模块的缺陷。

**其他实施发现**

| # | 缺陷 | 后果 |
|---|---|---|
| 1 | 正则缺前后边界 `(?<![0-9])` | 13 位数字误判为学号（**与后端 P1 同类**）|
| 2 | 凭据错误两套形状文案未收敛 | `{code:...}` 形状误显示「登录已过期」 |
| 3 | 两处测试自身写错 | ①断言整页 HTML 含禁用词（合规提示本就该含）②SSE 纯注释行应返回 null |
