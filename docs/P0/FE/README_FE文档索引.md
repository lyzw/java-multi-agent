### ⚠️ 实测排雷：zsh glob 漏搜差点误判后端 C1 未实现

首次 `grep -rln --include=*.java "ConfigController…"` 报 "no matches found" 零命中 →
**险些误判「后端 C1 未实现、前端无物可接」**。
实则 zsh 把 `--include=*.java` 里的 `*` 当作**未加引号 glob 展开**导致零匹配。
修法：加引号 `--include='*.java'`，并改用 `find … -name '*.java'` 交叉确认
`platform/agent-api/.../api/config/` 六文件（Controller/Response/Entry/Group/ZeroRetentionView/ReadService）已落地。

> 同源教训：*「看起来存在的防线，实际不存在」*——判定的依据是**实测可达的源码清单**，不是一句 grep 零命中。
