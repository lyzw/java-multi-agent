### F1–F3 交付明细（2026-10-19）

**工程**：`frontend/`（Vite 6.4.4 + React 18 + TS 5 严格模式 + Vitest 3.2.7）。

**验证结果（实测）**

| 项 | 结果 |
|---|---|
| 测试 | **112 项全绿**（pages 15 / scan 23 / runState 23 / errors 22 / sse 19 / idempotency 10）|
| 类型检查 | `tsc --noEmit` **零错误** |
| 生产构建 | 成功，203.70 kB（gzip 67.55 kB）|
| 产物密钥扫描 | **通过** |

**⚠️ 验证抓到的 P0 缺陷（已修复）**

`client.ts` 中 `login(payload)` 的形参名**遮蔽了同名的模块级 `request` 函数** →
运行时 `request2 is not a function` → **所有 HTTP 调用静默失败**。

> **为什么 5 个纯逻辑测试没发现**：它们都不经过 `client.ts`。
> **只有组件测试会真正发起请求**。分层测试有盲区——
> 不经过某模块的测试不会发现该模块的缺陷。

**其他实施发现**

| # | 缺陷 | 后果 |
|---|---|---|
| 1 | 正则缺前后边界 `(?<![0-9])` | 13 位数字误判为学号（**与后端 P1 同类**）|
| 2 | 凭据错误两套形状文案未收敛 | `{code:...}` 形状误显示「登录已过期」 |
| 3 | 两处测试自身写错 | ①断言整页 HTML 含禁用词（合规提示本就该含）②SSE 纯注释行应返回 null |

## FE-D4 缺陷清除（2026-10-20）

用户指令「继续前端代码优化」→ **先实测审计，再修复**。
立场：**150 项全绿不等于代码没问题**——全绿只证明「已写的断言成立」，
不证明「已声明的功能存在」。

审计方法：双向静态比对（`className` ↔ CSS 选择器）+ 运行时推理。
发现 **8 项缺陷**（编号 F-15～F-22，接续后端 F-1…F-14）。

| 编号 | 缺陷 | 严重度 |
|---|---|---|
| F-15 | `expiringSoon` 静默失效 + 到期提示功能从未落地 | **高**（声明了功能却不存在，且全绿）|
| F-16 | `<main>` 嵌套 + 两页未迁移 FE-D3 | 中（可访问性）|
| F-17 | 六个 CSS 类无任何定义（元素裸奔） | 中（视觉）|
| F-18 | FE-D2 §2.1「统一占位」决策未落地 | 中（一致性）|
| F-19 | `degraded` 判定自相矛盾 | 中（文案与界面冲突）|
| F-20 | React key 重复（**机理判断被探针推翻**）| 低（未定义行为）|
| F-21 | `normalizeNetworkError` 死代码 | 低 |
| F-22 | `hasRoleAccess` 四重死代码 | 低（补契约测试）|

**验证结果（实测）**

| 项 | 结果 |
|---|---|
| 测试 | **199 项全绿**（基线 150 + 新增 49），**连跑 3 轮稳定** |
| 类型检查 | `tsc --noEmit` **零错误** |
| 生产构建 | 成功，JS 230.60 kB（gzip 74.46）、CSS 10.74 kB（gzip 2.80）|
| 产物层复核 | F-17 的 12 个类**真的打进产物**；无 box-shadow / 无 shimmer；三断点在 |
| 反证 | 9 次注入，7 次精确转红，**2 次失败均有产出**（见 FE-D4 §6）|

> ⚠️ **本轮方法论上最重要的两条**：
> ① **F-15 是「声明了功能、有实现、有 150 项全绿测试，但运行时完全不存在」**——
>    与后端 F-10/F-12 同源。判定它靠的是读依赖数组，不是跑测试。
> ② **F-20 反证第一次没红**，逼出探针实验，**推翻了我对缺陷机理的判断**。
>    若没有这次反证，错误认知会随测试一起留在这里。
