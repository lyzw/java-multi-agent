## 1. `get_student_profile`（只读）

### 1.1 基本信息

| 项 | 值 |
|---|---|
| 工具名 | `get_student_profile` |
| 风险级别 | `READ` |
| 副作用 | **无** |
| 幂等要求 | 无（只读天然幂等） |
| 授权 | **学生仅可读本人画像**；跨租户一律拒绝 |

### 1.2 输入 Schema

```json
{
  "type": "object",
  "required": ["studentId"],
  "properties": {
    "studentId": {
      "type": "string",
      "pattern": "^stu_[a-z0-9]{16}$",
      "description": "随机学生标识。⚠️ 不得为姓名/学号（DEC-6 白名单）"
    }
  },
  "additionalProperties": false
}
```

> ⚠️ `additionalProperties: false` —— 多传字段直接拒绝，
> 不做「尽力解析」。这防止模型借机传入姓名、学校等被忽略的敏感字段。

### 1.3 输出契约

```json
{
  "studentId": "stu_a1b2c3d4e5f6g7h8",
  "grade": "初二",
  "subject": "数学",
  "weaknesses": [
    { "knowledgePoint": "一元二次方程", "errorType": "符号错误", "confidence": 0.8 }
  ],
  "updatedAt": "2026-10-01T00:00:00Z"
}
```

**白名单（DEC-6）—— 仅此四类，不得扩展**：

| 字段 | 说明 | 保留期 |
|---|---|---|
| `studentId` | 随机标识，不可反推身份 | 12 个月 |
| `grade` | 年级 | 12 个月 |
| `subject` | 学科 | 12 个月 |
| `weaknesses[]` | 知识点 + 错误类型 + 置信度 | 12 个月 |

> ⚠️ **禁止出现在输出中**：姓名、学校、班级、身份证号、手机号、
> 精确地理位置、面部/声纹、生物识别、社交账号。

### 1.4 错误语义

| 情形 | 行为 |
|---|---|
| 学生不存在 | 返回空画像（`weaknesses: []`），**不报错** |
| `studentId` 格式非法 | **拒绝**（Schema 校验失败） |
| 跨租户访问 | **拒绝**（`AccessDeniedException`） |
| 读取本人但无画像记录 | 返回空画像 |

> 「学生不存在」返回空而非报错：避免通过响应差异枚举有效 studentId。

### 1.5 缺失表的降级行为（若方案 B）

P2 阶段若表未就绪，**返回空画像而非报错**，保证链路可跑通。
⚠️ 但**必须显式标记** `degraded: true`，不得静默伪装成正常数据。

## 2. `record_weakness`（有副作用）

### 2.1 基本信息

| 项 | 值 |
|---|---|
| 工具名 | `record_weakness` |
| 风险级别 | `WRITE_PROFILE` |
| 副作用 | **写入薄弱点记录** |
| 幂等键 | `student_id + run_id + knowledge_point` |
| 授权 | 仅本人；**执行时重新授权** |
| 审批 | `WRITE_PROFILE=OPTIONAL`（DEC-11 初值） |

> **为何刻意保留有副作用工具**：P0-D00 §3.2 明确，这是首期唯一的有副作用工具，
> 用于实证验证红线 4/5/7（Attempt 区分、fencing、UNKNOWN 对账）。
> 没有它，最危险的协议就只在玩具环境里验证过。

### 2.2 输入 Schema

```json
{
  "type": "object",
  "required": ["studentId", "knowledgePoint", "errorType"],
  "properties": {
    "studentId": { "type": "string", "pattern": "^stu_[a-z0-9]{16}$" },
    "knowledgePoint": { "type": "string", "minLength": 1, "maxLength": 100 },
    "errorType": {
      "type": "string",
      "enum": ["概念不清", "公式记错", "符号错误", "计算失误", "审题偏差", "步骤缺失"]
    },
    "confidence": { "type": "number", "minimum": 0, "maximum": 1 }
  },
  "additionalProperties": false
}
```

> ⚠️ `errorType` 用**枚举**而非自由文本：
> 自由文本会让知识点无限发散，无法聚合分析，也会成为 Prompt 注入的载体。

### 2.3 幂等契约（**红线 4/5/7 的承载点**）

```
幂等键 = student_id + run_id + knowledge_point
```

| 情形 | 行为 |
|---|---|
| 同键 + **同请求摘要** | 返回首次结果，**不重复写入** |
| 同键 + **异请求摘要** | **冲突**，抛 `IdempotencyConflictException` |
| 首次 | 创建记录，状态 `PENDING → SUCCEEDED` |

> **摘要比对是关键**：若不比对，客户端换参数重试会被误判为重复，
> 导致「用户以为改了参数，系统返回旧结果」——比报错更难排查。

### 2.4 UNKNOWN 语义（红线 7）

写入请求已发出但响应丢失时：

```
❌ 不得当作普通 FAILED 重试   → 可能重复写入 = Sev-0
❌ 不得直接释放预算预留        → 成本可能已发生
✅ 只能通过 reconcile() 查询确定结果
```

| `reconcile()` 返回 | 处置 |
|---|---|
| 找到记录 | → `RECONCILED_SUCCEEDED` |
| 确认不存在 | → `RECONCILED_ABSENT` |
| **返回 null**（下游不可查） | → `MANUAL_DISPOSED`（**转人工，不重试**） |

> ⚠️ 「下游不可查」时**绝不能重试** —— 这是盲重试，等同 Sev-0。

### 2.5 fencing 契约（红线 5）

每次写入携带 `fencing_token`：

| 场景 | 结果 |
|---|---|
| 世代匹配 | 写入成功 |
| **旧世代写入** | **数据库拒绝**（`enforce_fencing_on_write` 触发器） |

> Worker 租约超时被接管后，旧 Worker 的写入会被直接拒绝。
> 这是**强保证**，不是软约束 —— 仅靠租约时间无法阻止双写。

### 2.6 输出契约

```json
{
  "recorded": true,
  "weaknessId": "wk_a1b2c3d4",
  "replayed": false
}
```

| 字段 | 说明 |
|---|---|
| `recorded` | 是否成功记录 |
| `weaknessId` | 薄弱点记录 ID |
| `replayed` | 是否为幂等重放（true 表示未重复写入） |

## 3. 两个工具的共同约束

### 3.1 执行链（不可跳过任何一步）

```
模型请求调用
  → Schema 校验        ← 非法直接拒绝
  → 执行时重新授权      ← 权限可能已撤销（红线 9）
  → 审批检查           ← 按 riskLevel 决定
  → 预算预留           ← 超预算拒绝
  → 执行
  → 账本写入           ← tool_operation 记录状态
```

> ⚠️ **禁止使用 Spring AI `ToolCallingAdvisor` 的自动执行路径** ——
> 它会绕过上述全部闸门（ADR-011）。

### 3.2 授权要求

| 工具 | 允许主体 | 拒绝情形 |
|---|---|---|
| `get_student_profile` | 学生读本人 | 读他人、跨租户 |
| `record_weakness` | 写本人 | 写他人、跨租户 |

> `tenant_id` **一律取自认证上下文**，永不信赖参数传入。

### 3.3 数据合规闸门

| 闸门 | 作用 |
|---|---|
| `ZeroRetentionGate` | 未确认零保留前，真实学生数据禁止进 Prompt |
| `DataClassification` | 检出身份证/手机号/学号/邮箱 → 拒绝 |
| `OutboxMessage` 白名单 | MQ 消息不含工具参数与学生数据 |
