# 单跑 IT 的极简口径：-Dtest=__none__ -Dsurefire.failIfNoSpecifiedTests=false -Dit.test=XXX
双 reactor verify 的三个隐性前提

① 本地库必须显式 IT_HOST=127.0.0.1 IT_PORT=5433 IT_ADMIN_USER=agent，否则 it-env.sh 在 source 阶段就因缺 AI_AGENT_PASSWORD 退出，Maven 根本没启动（看起来像构建失败）；② 不带 clean 会读到陈旧报告造成假红；③ mvn … | tee 必须配 set -o pipefail。
