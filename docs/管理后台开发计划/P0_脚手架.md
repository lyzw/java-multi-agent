# W-ADMIN-P0 · 脚手架：独立前端工程初始化、布局、路由、守卫、API Client 与仪表盘骨架

> **阶段目标**：以**独立前端项目**形态搭建管理控制台骨架——初始化独立 Vite + React 18 + TS 工程（独立 `package.json`/构建/部署），管理布局、路由、`TENANT_ADMIN` 守卫、API Client、设计令牌、M1 概览仪表盘骨架，并完成与**共享后端 `platform/agent-api`** 的代理/鉴权打通。这是后续 P0.5–P5 的统一承载底座。  
> **设计文档落点**：§1 总体架构、§4 页面结构与导航树、§7 技术选型、§1.1 集成要点（计划总览）。

---

## 0. 落地记录（2026-10-24）

- **工程位置**：`admin-console/`（仓库根下独立目录，独立 `package.json`/Vite/部署）。
- **部署形态（用户决策）**：**路径部署 + 同源反向代理**。
  - 控制台挂载在 **`/admin`**：Vite `base: '/admin/'`、Router `basename: '/admin'`。
  - 生产由 Nginx 将 `/admin/*` 指静态资源、`/api/*` 指共享后端 `platform/agent-api`（后端 `cors.disable()`，不走 CORS）。
  - 本地开发用 Vite devServer proxy 同源代理 `/api` → `127.0.0.1:8080`（可用 `VITE_DEV_API_TARGET` 覆盖）。
- **UI 框架**：采用 **Ant Design v5** + `@ant-design/icons`（管理后台 UI 框架），`AdminLayout`（antd `Layout`/`Menu`）实现侧栏+顶栏；未引入 `pro-components`（后续按需）。
- **鉴权**：复用共享后端 `POST /api/auth/token` 与 `GET /api/auth/roles`，令牌存 `sessionStorage['admin.session']`（独立键，与 `frontend/` 隔离）；角色仅导航显隐，安全以后端重授权为准。
- **验证**：`tsc --noEmit` 零错误；`vite build` 成功（3049 模块）；Vitest 4/4 通过。
- **当前状态**：P0 已完成；P0.5–P5 各模块以 `PlaceholderPage` 占位（路由 + RequireRole 守卫已就绪，待后端端点接入后填充）。

## 6. 风险与回滚

| 风险 | 缓解 / 回滚 |
|---|---|
| 独立工程与现有前端设计系统漂移 | 搬运既有设计令牌与 UI 模式到独立工程，令牌同源（§1.1 / §5.7） |
| dev proxy / CORS 缺失致 API 不可达 | Vite `server.proxy` 开发转发 + 生产同源反向代理优先；CORS 白名单兜底 |
| 登录/会话体系与共享后端不一致 | 复用同一 token 颁发与校验；`/me` 契约对齐后再接入守卫 |
| 路由冲突（与未来扩展） | 独立工程命名空间自洽，菜单按设计文档 §4 固定 |
