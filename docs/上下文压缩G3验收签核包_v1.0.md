## 2. 四链路 IT 证据（#101–#104，16 用例）

> 全部位于 `platform/platform-bootstrap/src/test/java/cn/studykid/multiagent/bootstrap/context/`，真库 `agent_it` 实跑；五类一次 verify 全绿（16 tests，`BUILD SUCCESS`）。

### 2.1 `CarryOverRoundTripIT`（L2 SSE carry-over，7 用例）

| 用例 | 钉死行为 |
| --- | --- |
| `validCarryOverInjectsCompactedFence` | 合法 HMAC 信封被接受，模型请求**恰一条** `<compacted_context trust="untrusted">` 围栏 |
| `hmacMismatchFallsBackToFullHistory` | HMAC 篡改 → 静默回落全量历史：无围栏、无 `error` 帧、Run 成功 |
| `expiredFallsBackToFullHistory` | `exp` 过期 → 同上 |
| `policyVersionMismatchFallsBackToFullHistory` | 策略指纹漂移 → 同上 |
| `tooLargeFallsBackToFullHistory` | 超过 `max-state-chars` → 同上 |
| `turnCursorAheadFallsBackToFullHistory` | `upToTurn` 超过本轮历史轮数 → 同上 |
| `tenantMismatchFallsBackToFullHistory` | 租户摘要不符（跨租户 state 不可复用）→ 同上 |

### 2.2 `SseHistory100TurnsWithinBudgetIT`（L2 SSE 预算与线序，3 用例）

- `hundredTurnHistoryIsTrimmedWithinBudget`：100 条 history 挤出压力下真命中 W2（after<before×4/5 且有 ASSISTANT 整轮被裁）；usage 按裁剪后请求计费；`answer → usage → context.checkpoint → done` 线序 + `Done.contextStateVersion`。
- `tenantChainSuppressesThinkingUnderSameBudget`：租户链同压力真裁剪，但 thinking 从源头丢弃（0 帧）。
- `shortHistoryStaysUntrimmedWithoutCheckpoint`：无挤出压力时 W0 逐字等价，不发第 14 事件、`Done` 退回 v1 旧字节。

### 2.3 `ConsoleChatMessagesWithinBudgetIT`（L3 预算，3 用例）

- `platformChainBudgetTrimsLargeHistory`：平台链 100 条 messages 真裁剪、tier∈{1,2}、真省 token、thinking 可见。
- `tenantChainSuppressesThinkingButStillBudgets`：租户链真裁剪但 thinking=0。
- `withinBudgetSmallHistoryUntouched`：短 history W0 不裁（before==after）。

### 2.4 `ConsoleChatDisabledPassthroughIT`（L3 关闭等价，2 用例）

- `disabledPassthroughSameReferenceNoTrim` / `disabledTenantChainPassthroughSameReference`：关闭态 100 条 messages passthrough **同一引用**、零预算、内容逐位不变（[D11] 关闭等价的构造级保证在 L3 真链路验证）。

### 2.5 `WorkerToolRoundPruningKeepsPairedMessagesIT`（L1 工具轮，1 用例）

- `tieredToolRoundPruningKeepsPairedMessages`：W2 整轮裁剪后**每一轮**送模型请求 tool_call↔call_id 配对闭合、首轮锚保留、真省 token、compaction 事件 tier≥2（Feign 对端「每个 tool_call 必须有配对结果」契约不破）。

## 3. IT 级四点撤点反证（#105，RV-M15-01…04）

脚本 `scripts/m15-chain-it-counterproof.sh`（`100755`，中断安全：Python 文件 IO 备份 + 备份完整性闸门 + `trap restore EXIT` / INT TERM 信号保护）。实测输出（2026-11-12）：

| RV | 撤点（生产修复点 → 临时替换） | 目标 IT | 结果 |
| --- | --- | --- | --- |
| RV-M15-01 | `ContextStateVerifierAdapter.verify` → 强制 `Accepted`（六项静默丢弃被撤） | `CarryOverRoundTripIT#hmacMismatchFallsBackToFullHistory` | ✅ 恰好红 1 条（篡改 HMAC 不再静默丢弃 → 围栏被注入 → 「围栏命中数=1，期望=false」） |
| RV-M15-02 | `AgentChatOrchestrator` 统一装配 → `passthrough(legacyRequest)` | `SseHistory100TurnsWithinBudgetIT#hundredTurnHistoryIsTrimmedWithinBudget` | ✅ 恰好红 1 条（捕获请求不再裁剪 → after 不降） |
| RV-M15-03 | `ConsoleChatController` → `return legacyRequest`（L3 预算端口被绕过） | `ConsoleChatMessagesWithinBudgetIT#platformChainBudgetTrimsLargeHistory` | ✅ 恰好红 1 条 |
| RV-M15-04 | `RunExecutionLoop` 统一装配 → `passthrough(legacyRequest)` | `WorkerToolRoundPruningKeepsPairedMessagesIT#tieredToolRoundPruningKeepsPairedMessages` | ✅ 恰好红 1 条（`assembled=false` → `onContextCompacted` 不触发 → compaction 事件空） |

- 每组形态：`Tests run: 1, Failures/Errors: 1, Skipped: 0`；恢复后五类 16 用例全绿（`BUILD SUCCESS`）。
- 收尾三件套全 ✅：OLD 锚点全量计数 1/1/1/1、残留 `// RV-M15-0X` = 0、md5 复原一致、`git diff --check` PASS。
- 意义：单元 / 守卫级反证只能证明「源码缺这些令牌」；IT 级反证证明**整条真链路**（HTTP → 编排 → 装配 → 围栏 → SSE/Console 字节 → DB）不是空转——撤掉任何一处生产修复点，真链路立刻以对应症状变红。
