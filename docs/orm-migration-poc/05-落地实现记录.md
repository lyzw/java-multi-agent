## 四、落地关键修正（相对 POC）

1. **版本锁定 3.5.17**（POC 写 3.5.15+）：本地缓存 3.5.15/3.5.17，选较新的 3.5.17。
2. **MP 3.5.17 包路径变更**（编译实证）：
   - `MybatisSqlSessionFactoryBean` 在 `com.baomidou.mybatisplus.spring`（非 `.extension.spring`）；
   - `PaginationInnerInterceptor` / `BlockAttackInnerInterceptor` 已**移出** `mybatis-plus-extension`；
   - 刻意不装分页插件（游标分页语义冲突），仅装自研 RLS 拦截器。
3. **platform 不能用 SpringManagedTransaction**：新增 `TenantBoundTransactionFactory`，借外层连接、提交/回滚/关闭全 no-op。
4. **RAG 场景相反**：默认 `SpringManagedTransaction` 恰好共享事务连接。
5. **只有核心 4 个波次完整实现**（2026-11-20 新增 W2 TenantAgentBinding + RateLimit）。
6. **TenantScope 嵌套安全**：适配层内部调用另一个适配层时，内层 clear() 恢复到外层主体，不串租户。
7. **RateLimit 的 check+increment 原子性必须保留**：CTE + ON CONFLICT + RETURNING，唯一索引是基础。

## 五、回滚开关（默认关闭，行为零变更）

两个 reactor 的 persistence POM 均引入 MP，但：

- SqlSessionFactory 与适配层 Bean 全部标注 `@ConditionalOnProperty(name="persistence.mybatis.enabled", havingValue="true")`；
- 旧 Jdbc*Repository 带互补条件（`havingValue="false", matchIfMissing=true`），或在 ApplicationConfiguration 里做 `mybatisEnabled ? new MybatisXxx(...) : new JdbcXxx(...)` 分支。

**结论**：未显式配置 `persistence.mybatis.enabled=true` 时，运行时行为与迁移前完全一致；开启即切换到 MP 实现；关闭即一键回滚。
