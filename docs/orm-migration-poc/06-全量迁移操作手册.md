# 全量迁移操作手册（W2 → W4 · 供批量执行使用）

> 前置必读：`04-POC-设计.md`、`05-落地实现记录.md`。本文件是「复制 W1 范式」的唯一权威精简版。

## 红线（任何一条违反即停止并回滚）

1. **Port 签名零改动**；上层 service / controller / DTO / 领域 record 一律不动。
2. **SQL 语义零改动**：原样搬进 Mapper XML，保留全部安全注释、`::uuid` / `::jsonb` 显式转换、`ON CONFLICT`、`FOR UPDATE`、CAS 条件、影子态钩子、审计 fail-closed。
3. **RLS 由代码保证且 fail-closed**：租户表查询必须经 `RlsTenantBindingInterceptor`；平台全局表必须走无拦截器工厂 + 显式 `TenantSessionBinder.clear(conn)`；禁止任何「以为 RLS 会兜底」的裸连接。
4. **默认关闭**：所有新 Bean 必须 `@ConditionalOnProperty(name="persistence.mybatis.enabled", havingValue="true")`，旧实现必须互补条件（`havingValue="false", matchIfMissing=true`）。
5. **不引入 MP 分页插件**（游标分页语义冲突）。

## 三种连接模型 → 三种工厂

| 模型 | 旧代码特征 | 新工厂 | 事务 | RLS |
| --- | --- | --- | --- | --- |
| A 外层事务借用 | `TransactionalConnectionHolder.inTransaction(...)` | 现有 `tenantSqlSessionFactory` | `TenantBoundTransactionFactory` | 拦截器 |
| B 自管连接 | `dataSource.getConnection()` + `TenantSessionBinder.bind(conn, ctx)` + `conn.commit()` | `selfManagedSqlSessionFactory`（待建） | 默认 `SpringManagedTransactionFactory`，每个 Mapper 调用一个 SqlSession | 拦截器 |
| C 系统/运维通道 | `openSystem()` / `TenantSessionBinder.clear(conn)` / platformOps DataSource | `opsSqlSessionFactory`（待建） | 默认 | **不装拦截器**（BYPASSRLS），XML 注释标明平台全局表 |

RAG 全部走 Spring `TransactionTemplate` → 使用现有 `rag` 工厂（默认 SpringManagedTransaction + `RagRlsBindingInterceptor`）。

## 单个 Port 的标准步骤

1. 新建 `*DO.java`（persistence 包）：`@TableName` / `@TableId` / `@TableField`；PG 类型配 `TypeHandler`；只保留持久化字段。
2. 新建 `*Mapper.java`：`extends BaseMapper<*DO>`（简单 CRUD）或纯 `@Mapper`（结果非表实体）；自定义方法签名与 Port 方法的 DAO 粒度一一对应。
3. 新建 `*Mapper.xml`：SQL 原样搬迁；`?` → `#{param}` / `@Param`；JSONB 保留 `::jsonb`；游标分页保留 `limit+1`。
4. 新建 `MybatisXxxRepository implements XxxPort`：Port 签名不变；内部委托 Mapper；影子钩子与审计调用按顺序保留。
5. 旧 `JdbcXxxRepository` 加互补 `@ConditionalOnProperty`；若是 bootstrap `@Bean` 装配，则在对应 `*Configuration` 上给旧 `@Bean` 加互补条件，给新 Bean 加开启条件。
6. 编译：`mvn -o -f platform/pom.xml compile -Dmaven.test.skip=true`（rag 同理）。
7. 守卫：`mvn ... -pl platform-bootstrap test -Dtest=DatabaseBoundaryTest`。

## 集中式装配（已由主代理完成，子代理不要改）

- `MybatisRlsConfiguration` / `RagMybatisRlsConfiguration` 已加 `@MapperScan`（`sqlSessionFactoryRef` 指向对应工厂）。
- 新增 Mapper 接口**不需要**加 `@Mapper`，只要放在 `basePackages` 覆盖的包下。
- `TenantScope` 已支持同一租户的嵌套 bind/clear；适配层内部可放心调用另一个适配层方法。
- 新适配器若与旧 `@Bean` 同类型竞争注入，主代理统一加 `@Primary` 与旧 `@Bean` 的互补条件；子代理不要编辑 `ApplicationConfiguration` 等共享配置。

## 完成判据

- 主代码全量编译通过；
- 两个边界守卫全绿；
- 该 Port 的现有单测（若有）全绿；
- 实现记录中登记文件清单与验证结果。
