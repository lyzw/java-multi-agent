C4 ASYNC dispatch 二次授权 → SSE 写不出终止块
完整		帧已逐条到达浏览器，但 Node fetch 读流 15 秒等不到 EOF，页面停在「正在生成」，curl 报 transfer closed；后端日志有响应提交后的 AuthorizationDeniedException。emitter.complete() 触发 Tomcat ASYNC dispatch；Bearer 过滤器是 OncePerRequestFilter，异步派发时不重复执行，SecurityContext 为空，二次授权抛拒绝而响应已提交 → 终止块写不出。单看业务代码完全正常。Node fetch 读流挂起 + curl transfer closed + 后端日志三处对照。两条链各加 .dispatcherTypeMatchers(DispatcherType.ASYNC).permitAll()（只放行容器在已完成 REQUEST 授权的同一请求上发起的派发，不绕过初始验签）；前端按 event:done 收口，不依赖 TCP EOF。验证：字节级 STREAM DONE normally in 1357 ms、帧 thinking×2/delta×3/done×1、双重包裹 0 行、AuthorizationDeniedException 0 条；计数守卫防后人当「多余配置」删掉。S4 §二 R4 L73-80
