迁移提示：治理不是「加字段」，是「可证伪的不变量」

Java 后端容易把合规理解为「表里加个 status 字段」。本册展示的是另一套：信任等级与版权分级是领域模型 + DDL 约束 + 检索 SQL 硬过滤三处一致；审计用触发器禁止 UPDATE/DELETE而不是靠约定；运维通道用独立连接池 + 方法名写死 Global + 启动自检而不是靠代码审查；作用域用 CHECK 约束 + 两层过滤同步守卫而不是靠 Repository 自觉。可复用的是「把不变量写进结构与守卫」；需要补的是「文档会滞后于代码三个版本」的时点意识——现场一定以可执行物为准。
