## 🏷️ 关键决策与架构约束

| 约束类型 | 规则 |
|---|---|
| **RLS 事务铁律** | `set_config('app.tenant_id',?,true)` 必须在事务内（自动提交后绑定失效） |
| **Repository 从不 commit** | 事务边界仅由 `TransactionalConnectionHolder` 持有 |
| **配置化三铁律** | fail-closed / Run 创建时快照隔离 / 只能收紧不能放松 |
| **测试双轨** | 行为测试（被直接调用时正确） + 连通性测试（是否真被调用，防断链） |
