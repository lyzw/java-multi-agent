- [ ] §9 行为测试四字段 + 具体原因码全绿（含 S3*、S4a/b/c、S5、S6、S8、S9）。

### 5.2 安全门槛
- [ ] RLS 跨租户隔离通过。

- [ ] 审批一次性与范围绑定（双哈希 + 消费时重验）通过。
- [ ] MCP 具名安全用例（SSRF/DNS/重定向/凭据）通过。
- [ ] fail-closed 全场景（版本不可用、存储不可用、未知风险）拒绝且 `reasonCode` 稳定。

### 5.3 工程门槛

### 5.4 硬约束
- [ ] **Demo ≠ 验收**：需求追踪矩阵中 Demo 与平台分列，无需求误标 `PLATFORM_IMPLEMENTED`。
- [ ] 平台 `cap_*` 自动化与故障注入全绿方为冻结依据。

## 8. 与整体平台计划的关系

本 W-PERM 工作流是平台 v3.1 计划「P3 可靠性与安全治理」中权限管控切片的独立细化。W-PERM-P6 冻结结论应回写整体平台计划 P3 门禁，作为平台进入 P4（企业集成与生产化）的前置证据之一。冻结未达成时，平台 P4 不得依赖本体系的生产就绪状态。
