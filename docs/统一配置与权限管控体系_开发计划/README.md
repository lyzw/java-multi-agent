## 与整体平台计划的关系

整体平台计划（Java SaaS Agent 平台 v3.1 软件开发阶段实施计划）使用 P0–P5 描述平台大闭环。本 W-PERM 是其「安全治理 / 权限管控」切片的独立细化：仅依赖平台 **P2 核心闭环 MVP** 与 **P3 可靠性基座**，内部细化为 **W-PERM-P0 ~ W-PERM-P6** 七个阶段，各自带独立门禁、责任分工与测试证据。
