# W-PERM-P5 · 发布审计与生命周期：CAS 发布、回滚、四字段/ledger 日志

> **阶段目标**：实现配置**原子发布（CAS 当前指针）**、生命周期状态机（DRAFT→VALIDATED→PUBLISHED→DEPRECATED）、回滚协议（不恢复撤权），以及贯穿决策与账本的**四字段 + ledger 维度审计日志**（审计 100%）。  
> **设计文档落点**：§6.2 引用与快照职责、§6.3 原子发布与并发控制（CAS）、§6.6 生命周期、§5.7 稳定原因码表（权威）、§7.4 双维度结果与对账、§9.2 PUB-1/PUB-2、附录 A 数据/发布检查项。

---

## 1. 目标与范围

| 范围 | 内容 |
|---|---|
| 原子发布 | 成功条件唯一：版本行插入 + release 记录 + 当前指针 CAS **同事务**提交；失败整事务回滚，无半成品当前发布 |
| 当前指针 | 平台级全局唯一当前指针；`config_publish_seq` 序列唯一；**当前版本不以 max(seq) 选择** |
| CAS | 基于 expected 基线更新指针；失败整事务回滚；同基线并发仅一次成功，失败方变基重试 |
| 回滚 | 保留原 release；新建回滚发布记录 + CAS 切指针；**不恢复 authzVersion / 旧审批**；ROLLED_BACK 仅审计旁路 |
| 生命周期 | DRAFT→VALIDATED→PUBLISHED→DEPRECATED；未发布不可被 Agent 启用；校验失败保持可修订不静默进 PUBLISHED |
| 审计 | 四字段 + ledgerPersistenceStatus + 原因码 + runId/invocationId/authzVersion/closureFingerprint 全量结构化日志；敏感字段脱敏 |
| 未知风险拒发布 | `riskLevel` 未知/非法 → 配置期拒绝发布（P1 运行期已拒；此处补配置期门禁） |

> 不在本阶段：行为四字段断言（P1/P2/P3 已覆盖）；本阶段聚焦发布链路与审计完整性。
