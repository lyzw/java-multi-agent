# W-PERM-P2 · 闸门与准入线性化：Gate 扩展、执行意图、防绕过

> **阶段目标**：把 Phase A 校验接入唯一执行入口 `ToolInvocationGate`，并按 §5.3 唯一协议实现 Phase B 执行准入（Idempotency→Schema→Approval→Budget→Ledger PRE→ExecutionAdmissionCheck→执行意图持久化→execute），核心是**准入点线性化（§5.5）**与**执行意图先于副作用（§5.3.4 13a）**。  
> **设计文档落点**：§5.3 唯一协议（步骤 8–14）、§5.5 撤权与执行准入线性化、§7.2 编排、§7.3 缓存、§7.4 双维度结果与对账、§8.3 防绕过 0。

---

## 1. 目标与范围

| 范围 | 内容 |
|---|---|
| Gate 扩展 | `ToolInvocationGate` 调度 §5.3（Phase A→B）；MCP-backed 与 Native 同一入口（ADR-011） |
| 准入线性化 | 步骤 13 准入检查成功时刻 = 线性化边界；撤权先于边界 → EXEC_ADMISSION_STALE 阻断；撤权后 → 在途不承诺取消，进对账（S3f） |
| 执行意图 | 步骤 13a 持久化 `executionIntent`（即将外部执行标记）**必须先于** ToolHandler.execute |
| 四字段贯通 | 全程产出 `authorizationDecision`/`executionDecision`/`executionStatus`/`ledgerPersistenceStatus`/`reasonCode` |
| 防绕过 | 静态扫描 + 运行时注入 + 包边界，0 通过（所有 Native/MCP 必经 Gate） |
| 缓存 | 缓存键含版本/指纹；命中后仍须权威新鲜度校验（§7.3）；不得将「仅全局序号变、闭包未变」视为授权失败 |

> 不在本阶段：审批双哈希/状态机/补偿（P3）、MCP 传输（P4）。

## 6. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 执行意图未先于副作用写入（崩溃窗口） | P2-T6 强制 13a 在 14 前；COMP-6（P3）硬门槛验证 |
| 撤权后准入边界判定漂移 | 边界 = 步骤 13 成功时刻；每次准入记录时间/版本/指纹/结果（§5.5.1） |
| 缓存误把全局序号变当授权失败 | P2-T9 显式排除「仅全局序号变、闭包未变」 |

## 7. 退出门禁

- [ ] `ToolInvocationGate` 严格按 §5.3 顺序编排；静态/运行时/包边界防绕过 **0 通过**。
- [ ] S1 成功路径四字段 + SUCCESS 通过；确定结果先于 POST 落盘（14a）。

- [ ] 缓存命中后仍做权威新鲜度校验；「仅全局序号变、闭包未变」不误判授权失败。
