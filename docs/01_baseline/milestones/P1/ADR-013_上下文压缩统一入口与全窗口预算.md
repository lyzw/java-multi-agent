| 字段 | 内容 |

| 影响模块 | `platform/`（12 → 13 模块）、`rag/`、`admin-console/`、`frontend/`、`deploy/sql/platform/`、`monitoring/` |

## 决策

1. 三条模型链路（Worker / SSE / 控制台直连）共用**一个** `ContextAssembler`，预算口径为**全窗口**：system + tools + memory + RAG + history + 当前输入 + 输出预留，不再沿用只统计消息序列的 `ContextBudgetTrimmer` 口径。
2. 压缩采用四级水位线 W0–W3，前两级零 LLM；W3 为增量结构化摘要 + 单调 seq 游标 + 可逆引用，绝不递归重摘要。
3. 新增第 13 个 Maven 模块 `agent-context`（纯 Java，零 Spring / JDBC / Hikari / Flyway），端口契约放 `agent-ports`；DB 写入只在 `agent-persistence`。
4. 三层配置：模型级 `model_catalog`（写入即生效）／Agent 级 `generation_params.context`（三步发布）／全局 `agent.context.*`（兜底 + 熔断）；**Run 创建时快照固化**，在途 Run 不漂移。
5. SSE 压缩态默认走**客户端 carry-over**，不落正文（零保留 / PIPL 未成年人）；`SERVER` 为显式例外。`context.checkpoint` 为第 14 个可选事件，协议升 v1.1 且两前端同批发。
6. `enabled=false` 时必须与「没有压缩功能」逐位一致（不多扣一个 token、不多发一个事件），作为一键回滚语义。
7. 压缩效果评测**绝不写** `agent_eval_sample`（其 verdict 只收人工裁定语义），走独立指标 + 人工样本。

## 备选与否决理由

| 备选 | 否决理由 |
| --- | --- |
| 仅保留滑窗裁剪 + 调大预算 | 丢任务锚，且不解决 system/tools/RAG 不进预算的静默超窗 |
| 每轮全量 LLM 摘要 | 每轮付费、首 token 延迟高、摘要递归漂移 |
| LLMLingua-2 做 token 级硬压缩 | 会破坏工具参数 / UUID / JSON；需新增小模型服务（列 P3，仅 rag 侧可选） |
| Spring AI ChatMemory / pgvector 语义召回 | platform 库未装 pgvector、`EmbeddingPort` 未实现（列 P3） |
| 训练式 compaction / KV-Cache 压缩 | 供应商侧能力，不在本项目控制范围 |

## 正向理由

复用五套既有范式：`ContextBudgetTrimmer`（按轮裁剪）、`run_message`（正文 + seq + 幂等）、`PromptGuard`（围栏）、`fencing_token` CAS、`cap_config_pointer` 版本机制。关键路径零 LLM；可逆引用保证信息可回取；fail-closed 与「不存敏感原文」的产品默认一致。

## 风险与约束

- 摘要丢用户纠正 / 显式约束 / 负向知识 / 精确数值（Sev-0）→ recall-first + 逐字 span + 针尖集 100% 约束召回。
- 粗估中英混合误差 30–50% → `usage.prompt_tokens` 校准 + `reserveRatio` + 硬顶二次校验。
- FORCE RLS 下的并发 / 隔离（Sev-0）→ CAS + 影响行数≠1 必抛 + 非特权真库 IT；禁用 `IN (SELECT … LIMIT … SKIP LOCKED)`。
- 新增表授权漏配 → `01` 终态 + `07` 幂等 ALTER + `02` 种子 + **重放 `03` 后紧跟 `04`** + `EXPECT_*` / 探针同步。
- record 加字段被兼容构造器静默清空 → 全参构造逐字段带过（铁律 #11）。
- 事务内 SQL 失败被 fail-soft 吞掉后 COMMIT → POISONED 边界（铁律 #12）。

## 迁移与回滚

分 P0–P3 四期，见开发计划 §3；主线 W1–W10（相对周），P3 单列。三级回滚：`enabled=false` → `strategy=OFF` → `TRIM_ONLY`。**P0 影子期严禁改变任何模型请求字节**，以「影子对照零差异」作为 G1 放行条件。

## 复审触发条件

① 换模型且窗口变化 > 2×；② 供应商提供精确 tokenizer / prompt caching；③ 平台库安装 pgvector；④ `context.estimation_error_ratio` P95 > 0.25 持续一周；⑤ 产品放开会话正文持久化（可切 `carryOver=SERVER`）。
