**⚠️ 本片最重要的根因定位：F-15 —— 「集成测试整体失效」的真凶是 fat jar**

此前台账记载 `ConfigEndpointIT` 引导失败「根因未定位」，并以
`-Dfailsafe.excludes='**/ConfigEndpointIT.java'` 排除后取数。**本片已定位**：

| 事实 | 说明 |
|---|---|
| 现象 | `platform-bootstrap` 下**每一个** `*IT` 类在 `mvn verify`（failsafe）中都报「Failed to find merged annotation for @BootstrapWith」|
| 关键对照 | 同一个类改走 surefire（`mvn test`）**完全正常** |
| 根因 | `spring-boot-maven-plugin:repackage` 在 package 阶段把主构件替换成 Spring Boot **fat jar**，其类位于 `BOOT-INF/classes/`——那是 Spring Boot 自定义类加载器的布局，**failsafe 的普通 classloader 读不到** `PlatformApplication` → `@SpringBootTest(classes=…)` 内省抛 `TypeNotPresentException` → 元注解 `@BootstrapWith` 无法内省 |
| 修法 | 给 `repackage` 挂 `<classifier>exec</classifier>` → 主构件保持 **thin jar**（类在根目录），可执行胖包另出 `platform-bootstrap-…-exec.jar`（Spring Boot 官方标准做法）|
| 效果 | **本模块集成测试整体复活**：127 → 143（+16 = ReadEndpointIT 12 + ConfigEndpointIT 4）|

| 标记 | 含义 |
