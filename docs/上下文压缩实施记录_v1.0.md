### 2.3 评测集规格（W1 立项，S5 前交付）

- **针尖集**五类必须逐字保留的 span：① 用户纠正（「不要…」）② 显式约束 ③ 负向知识 ④ 精确 UUID / 数值 ⑤ 知识点 / 错误类型；约束与纠正类召回 100%，其余 ≥95%，且 `source_message_ids` 可回取原文。
- **A/B**：同一批真实 `run_message` 轨迹离线回放，`enabled=false` vs `TIERED`；judge 用不同模型族 + A/B 换位；金标准是下游任务成功率。
- **样本量**：≥30 组配对样本才展示百分比；n<30 只给定性结论，**绝不编造归因正确率**。
- **闭环断言**：真跑一次 → `usage_record` 输入 token 真的下降 → checkpoint 落库 → 下一轮复用 → 答案关键事实与未压缩版一致。
