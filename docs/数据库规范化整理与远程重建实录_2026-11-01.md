### 2.2 收敛过程中发现并修复的存量缺陷

1. **02 附录 A 空库复放必炸**：`setval('cap_config_publish_seq', coalesce(max,0))` 在空表时
   setval(0) 越界（序列下界 1）。该附录 2026-10-29 为存量库补写、从未在空库验证过。
   已修为「空表归位 1（is_called=false）→ 非空追到 max」。
2. **02 种子只有 t-a**：IT 依赖的 t-b 夹具此前靠「老库残留」存在，删库重建后会凭空消失 ——
   正是靠空库复放验证才暴露。已按「三处齐」形状固化进附录 B。

## 3. 远程重建实录

```
① 终止 5 库全部应用连接（pg_terminate_backend；连接池会重连，DROP 用「终止+删除」同会话重试）
② DROP DATABASE agent_it / agent_e2e / agent_ci_sim
③ DROP DATABASE agent_dev → CREATE DATABASE agent_dev OWNER ai_agent
④ scripts/init-db.sh platform --db agent_dev ...        → 自检全绿
⑤ study_rag：终止会话 → DROP SCHEMA rag CASCADE（public/vector 扩展保留）
⑥ scripts/init-db.sh rag --db study_rag ...             → 自检全绿
⑦ 删除 agent_init_verify 临时库
```

**权限处理（用户账号控制）**：角色均为集群级对象，DROP DATABASE 不影响，无需重建；
重建后由 03/04 角色脚本重新授权（GRANT 只覆盖执行时已存在的表，故必须后于 DDL 执行）。
唯一新增：`agent_retention`（NOSUPERUSER + NOBYPASSRLS，仅 audit_record / erasure_certificate 的 DELETE），
口令已配置；应用侧启用对应 `agent.retention.datasource.*`（RetentionDataSourceConfiguration）即可点亮 G3。

## 6. admin-console 平台账号初始化（重建后补装）

重建完成后，按用户提供的清册把 6 个 admin-console 平台账号初始化进 `agent_dev`
（工具：`scripts/tools/SeedPlatformUsers.java`，即 `scripts/dev-seed-platform-users.sh` 的底层实现；
连接身份 `platform_ops`，口令经环境变量 `SEED_ACCOUNT_PASSWORD` 传入、不落仓库）：

| 账号 | 密码 | 角色 |
|---|---|---|
| plat-superadmin | （统一口令，见线下台账，不入仓） | PLATFORM_SUPER_ADMIN |
| plat-lifecycle | （同上） | TENANT_LIFECYCLE_ADMIN |
| plat-resource | （同上） | PLATFORM_RESOURCE_ADMIN |
| plat-security | （同上） | PLATFORM_SECURITY_ADMIN |
| plat-auditor | （同上） | PLATFORM_AUDITOR |
| plat-support | （同上） | PLATFORM_SUPPORT |

> ⚠️ 六个账号使用用户线下提供的同一口令（`SEED_ACCOUNT_PASSWORD` 传入）。按仓库纪律
> 「口令不入哈希、不入仓」，本表不落明文；如需轮换，走工具 `--reset`。

- 哈希由服务端同一实现 `PrincipalRepository$PasswordHasher`（PBKDF2-HMAC-SHA256 600k 迭代）现算，`varchar(256)` 存 `password_hash`，`auth_source=LOCAL`、`status=ACTIVE`、`mfa_required=false`。
- 流程：先 dry-run（回滚）确认 6 账号建号 + 绑角 + 回读验密全过 → `--commit` 提交；psql 独立复核 6 行齐、hash_len=90。
- 幂等：username 唯一键 + (user,role) 主键均 DO NOTHING，可重复执行；改口令走 `--reset`。
- `granted_by`：默认授权人 `e2eadmin` 不存在（全新库），已按 nil UUID 记账（工具内建提示，可事后更正）。
