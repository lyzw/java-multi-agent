一、项目概况与技术基线

本项目是租户侧的辅导业务控制台（区别于另一套 admin-console 平台治理后台）：面向学生/家长/老师，提供"发起辅导 → 进度追踪 → 归因结果 → 学习画像"，以及知识检索（RAG）、语料治理、配置、运行治理（审批/未知操作处置/审计）、报表、系统健康等能力。共 16 个导航入口、约 19 个页面路由。

二、UI 层面评估

2.1 视觉布局

采用顶栏 + 侧栏布局（src/layouts/AppShell.tsx）。侧栏按 4 个业务分面分组：辅导台 / 知识库治理 / 运行治理 / 平台配置与运维，每个分面带角色提示（rolesHint），导航项按用户角色动态过滤（visibleNav，AppShell.tsx:187-192）。顶栏含品牌标识、角色/租户身份、折叠按钮、退出按钮。整体信息架构清晰，分组语义合理，重度用户可把侧栏折叠为图标栏并跨刷新持久化（nav.collapsed localStorage，AppShell.tsx:122, 179-185）。

2.2 配色与字体

配色由完整的 CSS 设计令牌驱动（src/styles/tokens.css），全局零硬编码十六进制色值（在 *.tsx/*.ts 中 grep #xxxxxx 命中数为 0）。令牌包括：纸面 --paper #fcfcfb、墨色三级 --ink / --ink-2 / --ink-3（其中 --ink-3 #8a9099 被令牌注释硬性约束只用于非文字装饰，承载文字一律用 --ink-2 以满足对比度）、语义色 --mark #c8382d（批改红，仅用于错误/失败）、--settled #1d6b5c（完成/通过）。字体为系统 UI 栈 + 宋体（--font-hand，用于"纸感/批改"签名）+ 等宽（--font-mono）。这套"纸面 + 墨色 + 批改红"的视觉语言一致、克制、辨识度高。

证据：tokens.css:22-56（令牌定义与对比度纪律注释）。

2.3 组件一致性

高度一致。全站贯彻"五态纪律"（默认 / 加载 / 空 / 错误 / 未开放，FE-D3 §4），由共享组件统一承载（src/shared/states.tsx）：

  • Loading（呼吸纸面，role=status + aria-live，states.tsx:135-141）——刻意不用灰色微光条；
  • Empty（states.tsx:182-207）——注释明确"⛔ 不写'暂无数据'这种死话"，必须给下一步引导；
  • ErrorState（states.tsx:224-246，role=alert）——"说明原因 + 可执行下一步"，不道歉、不写"请求失败"；
  • Unavailable（states.tsx:269-291）——与"空"严格区分：接口未接上 → 标注后端缺口编号（如 G14），避免用户反复刷新等一个永远不会来的结果；
  • CapabilityNote / Sheet / Marked / Breadcrumbs / ListFooter 均为单一真相源，杜绝各页各抄一份。

同页头组件 PageHead 统一同步 document.title（usePageTitle），避免了 SPA 切页标题不变的问题（App.tsx:72-79 注释详述了一次因此产生的缺陷修复）。

2.4 响应式与易用性

这是本项目相较 admin-console 最显著的亮点。响应式是纯 CSS 驱动（源码 grep 确认无 matchMedia/useMediaQuery/ResizeObserver/window.innerWidth 监听，无 JS 布局抖动）：

  • @media (max-width:1023px)、(max-width:767px)、(max-width:479px) 三档断点（layout.css:700/753/790/938）；
  • ≤767px 侧栏从"16 项横向滚动条"改为顶栏菜单按钮拉出的抽屉，且抽屉具备完整焦点管理：打开时焦点进入抽屉、Esc/点遮罩/点导航项可关、关闭后焦点回按钮、打开时锁背景滚动、收起用 visibility:hidden 移出焦点序列与无障碍树（AppShell.tsx:123-177）。

可访问性扎实：壳内首个可聚焦元素是 skip-link（AppShell.tsx:225）、aria-live 状态区、role=alert 错误、ARIA tabs（roving tabindex + 方向键）、sr-only 文件输入、图表等价表格、aria-describedby 错误关联、按钮 aria-busy/aria-disabled。

UI 小结：在"无组件库、纯手写"的约束下，本项目的视觉一致性、令牌纪律、响应式与可访问性都达到优秀水平，是"克制设计 + 强纪律"的正面范例。admin-console 的"响应式几乎缺失 / 颜色内联硬编码"问题在本项目基本不存在。

三、业务流程层面评估

3.1 核心路径（登录 → 辅导 → 结果）

  1. 登录（pages/LoginPage.tsx）：三字段（租户标识 / 账号 / 密码），前端完整性校验齐全——isComplete 计算（:41）、按钮 disabled={submitting || !isComplete} + aria-busy + aria-disabled + "请填写所有必填字段"提示（:173-187）。失败统一提示"租户、账号或密码不正确"，刻意不区分原因以防账号枚举（:4-6）。无功能性阻断。注意：按设计不提供"忘记密码/注册/多租户切换"（PIPL 不采集邮箱/手机，注册需监护人同意流程），属合规取舍而非遗漏。
  2. 发起辅导（pages/NewRunPage.tsx）：表单含 Agent 选择，DEFAULT_AGENT_ID 兜底；Agent 列表为空时显示"没有可用的 Agent"提示块（:354-362，而非隐藏下拉），前端敏感信息预扫 + 幂等键。路径顺畅。
  3. 分析进度（pages/RunProgressPage.tsx）：事件轮询 + 明确卸载清理（避免定时器泄漏），aria-live 状态区，到终态自动停；无事件时降级占位而非假装进度（:192）。
  4. 归因结果（pages/business/RunResultPage.tsx）：findLeakedFields 敏感词扫描 + useMemo 截断 slice(0,10000)（:100-105），仅渲染白名单字段；提供反馈按钮。

3.2 其余模块

学习画像知识检索 RAG语料治理配置运行治理报表系统健康
  • 学习画像：纵深防御，只渲染 studentId/年级/学科/薄弱点 白名单，不显示姓名/学校/班级（PIPL）；后端 200+notFound 被当作合法态诚实呈现（ProfilePage.tsx:103-126, 181-185）。
  • 知识检索：携带 X-Tenant-Id；租户标识记忆带 7 天 TTL（RagSearchPage.tsx:94-119）。
  • 语料治理：ARIA tabs 模式 + 批量导入带分批改进度 + <progress> + 字典区分动态/派生只读（RagManagementPage.tsx）。
  • 配置：只读目录 vs 可写覆盖分层；保存前 window.confirm + 理由≥10 字 + 只收紧不放松（ratchet，ConfigOverrideRow.tsx:87-91, 196-200）。
  • 运行治理：审批（通过/驳回带理由）、未知操作处置（UNKNOWN 终态归档、无重试，Sev-0 产品边界）、审计（游标分页 + CSV 导出）。
  • 报表中心：7 张报表 + 页首锚点；DAY_OPTIONS=[7,14,30,90] 固定下拉（后端钳制 1~90）；Chart.tsx 零依赖 SVG（role=img + 等价表格）；csv.ts 含 UTF-8 BOM + 防公式注入。
  • 系统健康：仅显示总状态（见问题清单 P1）。

3.3 阻断与困惑点

无功能性阻断。主链路与设计边界均清晰，fail-closed（角色未知不放行、未接入能力显式标注、敏感数据不出前端）。潜在困惑点：① 报表选 90 天后端"静默截断"仅以小字 hint 提示，无"已截断至 X 天"回显；② 治理/审批/审计列表明确不自动轮询（限流取舍），但页面缺"最后刷新时间/数据可能非实时"提示，操作员可能误以为实时；③ 学习画像查询仅判空、无编号格式校验（任意字符串会走到后端 notFound 态，体验可接受但缺即时反馈）。

六、优势沉淀

  • 五态纪律全站贯彻，错误态统一"说明原因 + 可执行下一步"，不编造、不道歉、不假装进度——这是多数项目做不到的。
  • 颜色令牌零硬编码（TSX 内 hex grep = 0），"纸感 + 墨色 + 批改红"主题一致，语义色只有 --mark/--settled 两色，视觉克制。
  • 真响应式：纯 CSS 断点 + 小屏抽屉 + 完整焦点管理，与 admin-console 的"响应式缺失"形成鲜明对比。
  • 诚实边界：notFound 合法态、环比为 0 不给 %、准入率分母含未审、活跃=错因去重而非登录数、未接入能力显式标注缺口编号。
  • 无障碍较扎实：skip-link、aria-live、role=alert、roving-tabindex ARIA tabs、图表等价表格、aria-describedby 关联。
  • 零依赖攻击面：图表纯 SVG、CSV 纯前端、无图表/组件库；构建体量仅 403 KB JS。
  • 路由健康度：404 不再静默跳工作台（App.tsx:185-190）、路由切换滚动复位、PageHead 统一标题、死链 /profile/current 已修复为查询页。
