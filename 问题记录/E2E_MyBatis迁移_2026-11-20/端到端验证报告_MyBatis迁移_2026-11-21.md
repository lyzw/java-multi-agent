# 端到端验证报告：MyBatis 迁移（admin-console + frontend 真实浏览器驱动）

- 日期：2026-11-21（环境准备始于 2026-11-20）
- 方式：真实浏览器（agent-browser）驱动两个前端工程 + 真实数据库（RDS agent_dev / RAG 库）+ 真实 MQ
- 开关：`PERSISTENCE_MYBATIS_ENABLED=true`（platform 与 rag 双服务）
- 服务：platform:8080、rag:8081、admin-console vite:5180、frontend vite:5173、ollama:11434（嵌入）

## 一、结论

**除「模型推理」因 MiniMax 余额不足（402，环境计费问题）无法完成外，MyBatis 迁移链路全部打通**。过程中发现并修复 **9 个迁移缺陷**（全部是 MyBatis 装配/SQL 语义问题，JDBC 原实现无此问题）。

## 二、发现并修复的缺陷（9 个）

### admin-console 轮次（2026-11-20）
1. **AuthzShadowConfiguration Bean 冲突**：MyBatis 开启后 `AuthzDecisionRecorder` 出现双实现（NoUniqueBeanDefinitionException），启动失败 → 修复装配条件。
2. **AuthzDecisionLogGuard 类型强绑**：守卫硬性要求 `JdbcAuthzDecisionLog` 实例 → 改为探测探针语义，MyBatis 实现可过守卫。
3. **RunClaimMapper.xml RETURNING 误用 `<update>` 标签**：claimBatch/claimSpecific/claimParkedForResume 三条带 `RETURNING` 的语句必须用 `<select>`，否则返回值静默丢失 → 已改。
4. **PlatformAgentDirectoryMapper 装配错通道**：平台 Agent 注册表（全局表、无 RLS）被装配进租户 SqlSessionFactory → XML 移至 `mapper/ops/`，走运维通道；修复后 API 返回真实数据（此前空列表）。

### frontend 轮次（2026-11-21）
5. **pg_notify Mapper 映射**：`resultType="void"` 不是合法别名、无 resultType 又映射到 `void` 类均失败 → 改为 CTE 包装返回 boolean，方法签名 void 丢弃结果。
6. **RLS 租户漂移误报**：`MybatisConfigPointerRepository` PLATFORM 哨兵（零 UUID）在租户绑定连接上执行被 `RlsTenantBindingInterceptor` 判为漂移 → 拦截器对齐 JDBC 嵌套事务语义（哨兵目标不视为漂移、不重绑；反向仍拒绝）。修复依据：`cap_config_pointer_read` 策略对 `tenant_id IS NULL` 行天然放行。**修复后 CONFIG_UNAVAILABLE 消失，能力快照成功解析**。
7. **markOutboxPublished 时间绑定**：String→varchar 写 timestamptz 列报 BadSqlGrammar → 参数改 `Instant`（JSR-310 TypeHandler 以 Timestamp 绑定，对齐 JDBC `setTimestamp`）。
8. **insertRun 语义漂移**：`deadlineAt` String（非空时同样报错）、`budgetAmount` 缺省写 0（DDL 注释明确 `NULL = 不额外限制`，写 0 会让 Run 变额度为 0 的僵尸 Run）→ 改 `Instant` + `BigDecimal`，null 直传。
9. **updateReservationState 引用不存在的列**：`budget_reservation` 没有 `updated_at`，且丢 `settled_amount/settled_at/release_reason` → 按 JDBC 语义拆成 `settleReservation`（SETTLED+settled_amount+settled_at）与 `releaseReservation`（RELEASED+release_reason）。

## 四、环境阻塞（非迁移缺陷）

1. **MiniMax 402 insufficient_balance**：agent-chat/default 全场景仅配置 MiniMax-M2.5，余额耗尽 → 辅导/通用问答/Agent 对话的模型推理无法完成（Run 干净收敛 FAILED/RECOVERY_RETRY_UNAVAILABLE）。**需充值或切换模型后复验「成功完成辅导」的完整 happy path**。
2. **ollama（11434）未启动**：RAG 嵌入不可用 → 已启动本地 ollama（qwen3-embedding:8b）后检索恢复。
3. 知识检索默认版本坐标（七年级/人教版）无语料为**数据覆盖问题**（页面有明确引导），跨版本查找命中沪教版语料。
