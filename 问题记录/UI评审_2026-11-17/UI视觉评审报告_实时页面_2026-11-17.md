## 三、实时页面仍存在的问题（编号 L1–L5）

### L1　学生端对话页把大量技术术语与调试开关暴露给学生　`[V2 层级 / V7 对比 / V6 密度]`
- **位置**：学生端「通用问答」页、「Agent 对话」页。
- **可见现象**：两页顶部各有一段红色小字说明框，内容含 `/api/knowledge/agent/chat/stream`、`404/501`、`SSE`、`Run 审计`、`RAG_CORPUS_QA_SYNC_PIPELINE`、`MinMax-Max+2.5`、`token 流式` 等术语；Agent 页还整块展示「编排设置」区（数据来源=样例回放、回放场景、指定 AgentId、RAG topK、thinking 模式勾选）。「通用问答」的"对话设置"里也有"通道：租户 SSE · 逐 token 流式"。
- **影响**：这些页面面向的是做错题辅导的学生，技术说明与调试参数既看不懂又占据首屏显要位置，低对比小字增大阅读负担，主次颠倒。
- **建议**：面向学生的界面移除或折叠这些技术说明与编排参数（它们更适合留在管理后台）；若需保留可访问性提示，改为一句人话，如"回答可能无法完全溯源的会标注出来"。
- **复核条件**：学生端对话页首屏不再出现 API 路径、SSE、topK、thinking 模式等技术字段。
- **标注**：`live/annotated/live05-general-chat__anno.png`、`live06-agent-chat__anno.png`

### L4　管理后台 AI 对话页顶部说明框技术细节过载　`[V2 层级 / V6 密度]`
- **位置**：后台「AI 实验室 → AI 对话」页。
- **可见现象**：首屏最醒目的蓝色提示框塞满 `/api/v1/retrieval + /api/v1/retrieval/generate`、`EXCERPT_ASSEMBLY`、`RAG_CORPUS_QA_SYNC_PIPELINE`、`MinMax-Max+2.5`、`RAG_CORPUS_QA`、`X-Tenant-Id 404`、`$...$/$$...$$/\\[...\\]` 等约 4 大条 API/内部枚举说明；下方黄色框又是一段 `X-Tenant-Id` 请求头与 400 的技术说明。
- **影响**：管理员进来第一眼是整屏技术说明，真正的操作区（对话参数、输入框）被压到下方。
- **说明**：管理后台面向管理员，技术说明的合理性高于学生端，但当前密度仍偏高、层级喧宾夺主。
- **建议**：把长说明收进可展开的"技术说明"区，默认收起；首屏保留一句概述 + 操作区。
- **复核条件**：进入页面第一视觉焦点是操作区而非大段技术说明。
- **标注**：`live/annotated/live09-admin-ai-chat__anno.png`

### L3　管理后台列表页表格下方大面积空白　`[V6 留白与密度]`
- **位置**：后台「租户管理」页。
- **可见现象**：表格仅 3 行数据，表格卡片下方约六成区域纯白，页脚版权信息贴底。
- **影响**：低信息密度下留白失控，页面显空旷。
- **建议**：数据少时让卡片高度贴合内容，或在空白区补统计概览/引导。
- **复核条件**：卡片高度随内容收缩或空白区有实质内容。
- **标注**：`live/annotated/live08-admin-tenants__anno.png`

### L2　后台状态徽章与占位符语义不统一　`[V5 一致性]`
- **位置**：后台「租户管理」页。
- **可见现象**：生命周期用绿色描边英文 `ACTIVE`；「套餐」列 3 行全是灰色 `-`，与"无数据/不适用"含义混用且无图例。
- **影响**：中英混用、`-` 无说明，不易形成稳定预期。
- **建议**：状态徽章统一语言与形状；`-` 改为"未配置"或在表头/图例说明其含义。
- **复核条件**：跨页同类状态外观一致，占位符有明确含义。
- **标注**：`live/annotated/live08-admin-tenants__anno.png`

### L5　失败进度页正文重复完整运行标识、文案啰嗦　`[V3 可读性 / V6 密度]`
- **位置**：学生端失败 run 的「分析进度」页。
- **可见现象**：红色失败框已给出中文原因；其下一段灰色说明又重复一遍完整 UUID（"运行标识 c555e8e7-cd1d-44d1-b484-2584b7b8ff15"），而页面顶部"运行标识"行已显示过该值。整句"这不是网络抖动或题目内容问题…重试不会改变结果，请联系管理员"偏长。
- **影响**：同一长标识重复出现、对用户无意义，正文啰嗦分散注意力。
- **建议**：正文不再重复运行标识（顶部已有），把引导语精简为一两句。
- **复核条件**：失败说明段不再重复完整 UUID。
- **标注**：`live/annotated/live07-progress__anno.png`
